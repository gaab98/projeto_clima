# Atribuições e Créditos de Terceiros

Este projeto utiliza as seguintes bibliotecas e serviços de código aberto:

## Fontes
- **Bricolage Grotesque** por Mathieu Triay (Atelier Triay), distribuída via Google Fonts
  - Derivada de Mayenne Sans, de Jérémy Landes
  - Licença: SIL Open Font License 1.1
  - URL: https://fonts.google.com/specimen/Bricolage+Grotesque
  - Código-fonte: https://github.com/ateliertriay/bricolage

## Ícones
- **Weather Icons** v2.0.10 por Erik Flowers (ícones originais de Lukas Bischoff)
  - Licença: SIL OFL 1.1 (fonte) + MIT License (código/CSS)
  - URL: https://github.com/erikflowers/weather-icons

## APIs e Dados
- **Open-Meteo API** (previsão do tempo)
  - Licença dos dados: CC BY 4.0
  - URL: https://open-meteo.com/
  - Atribuição: Dados meteorológicos fornecidos por Open-Meteo.com
  - Observação: o uso comercial exige chave de API (ver https://open-meteo.com/en/pricing)
- **Open-Meteo Geocoding API** (nome da cidade para latitude e longitude)
  - Dados de localização baseados em GeoNames (licença CC BY 4.0)
  - URL: https://open-meteo.com/en/docs/geocoding-api
  - GeoNames: https://www.geonames.org/
